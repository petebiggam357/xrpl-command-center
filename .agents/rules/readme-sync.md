# Documentation & README Synchronization Rule

- **Always update `README.md` on feature changes:** Whenever new features, modules, hardware integrations, CLI/packaging changes, or behavioral updates are added to this repository, update `README.md` in the same change set so feature tables, architecture diagrams, shortcuts, security notes, and release/install filenames stay 100% aligned with the codebase.
- **Verify before committing/releasing:** Before committing or tagging a release, review `README.md` to confirm every new capability, supported OS artifact name, and test count matches the actual implementation.
